# 英語 音読チェック（試作品）

指定した英文を音読すると、発音をチェックする練習用の試作品です。下校時刻システムとは独立しています。

## 起動

```
npm run ondoku          # http://localhost:3100
```

| 環境変数 | 内容 |
|---|---|
| `GEMINI_API_KEY` | Gemini の鍵（「AI にくわしく見てもらう」に必要） |
| `GEMINI_MODEL` | 使うモデル（省略時 `gemini-flash-latest`） |
| `PORT` | ポート番号（省略時 3100） |

マイクは https か localhost でないと使えません。

## しくみ

1. **その場の判定（無料・端末内）**：ブラウザの音声認識（Chrome・Edge・Safari）で聞き取った文を見本と単語ごとに比べ、合っている／おしい／ちがう／ぬけ に色分けして点数を出します。日本人に多い取り違え（th→s、r→l、v→b、f→h）は「おしい」と判定します（`lib/compare.js`）。
2. **AI のくわしい助言（ボタンを押したときだけ）**：録音を Gemini に送り、どの単語のどの音が苦手か、どう直すかを日本語で返します（`lib/gemini.js`）。

- 見本文は `lib/passages.js`。画面で自由な英文も入れられます。
- 単語を押すと見本の発音（端末の読み上げ）が聞けます。
- 録音はサーバーに保存しません（Gemini に送って返事をもらうだけ）。

## 注意（試作品の限界）

- その場の判定は「音声認識が単語を聞き取れたか」で見ているため、細かい音の癖までは分かりません。そこは AI の助言で補います。
- Firefox は音声認識がないため、その場の判定は出ません（AI の助言は使えます）。
- 生徒に使わせる場合は、録音が Google に送られることを保護者に説明してください。
