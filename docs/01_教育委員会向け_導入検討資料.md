# 利根沼田 下校時刻共有システム 導入検討資料（案）

> 教育委員会で導入の可否を判断していただくための資料です。
> 「システムで対応済み」「資料・規程で対応」「協議して決めること」に分けて整理しています。
> 法令・ガイドラインの名称や最新の改訂内容は、提出前に必ず確認してください。

## 1. 概要

| 項目 | 内容 |
|---|---|
| 目的 | 小学校が決めた下校時刻を、学童（放課後児童クラブ等）と保護者へ、正確に・すぐに・漏れなく伝える |
| 対象地域 | 沼田市・みなかみ町・川場村・片品村・昭和村 |
| 利用者 | 学校（入力・公開）、学童（受信・確認）、保護者（閲覧・通知）、市町村と連絡協議会（アカウント管理） |
| 扱う情報 | 学年ごとの下校時刻と備考のみ。**児童の氏名・住所など個人を特定する情報は扱わない** |
| 利用方法 | パソコン・スマホのブラウザのみ（アプリのインストール不要） |

### 期待される効果
- 学校：学童と保護者への個別連絡・問い合わせ対応が減る。誰に伝わったか画面で確認できる
- 学童：各校からの連絡を探したり書き写したりする手間とミスがなくなる。急な変更に気づける
- 保護者：変更がスマホに届く。学校への問い合わせが不要になる

## 2. 管理体制（案）

**特定の民間事業者（開発した学習塾を含む）は、システム内の管理権を持たない**形にしています。

```
連絡協議会（利根沼田の5市町村で構成。事務局は幹事市町村の教育委員会）
  ├ 全体設定、バックアップ、保存期間を過ぎたデータの削除、全体の操作履歴の確認
  └ 市町村の管理者（各市町村の教育委員会／学童担当課）
      ├ 自分の市町村の学校・学童の登録、アカウントの発行・停止
      └ 学校・学童の管理職（校長・教頭、施設長）
          └ 自校・自施設の職員アカウントの発行・停止（人事異動への対応）
```

- 学童（放課後児童クラブ）は福祉部局の所管であることが多いため、**学校は教育委員会、学童は学童担当課**が管理できるよう、市町村の中でも担当を分けられます。
- 開発者は「技術的な保守の受託者」または「無償提供者」の立場にとどまり、利用者としての学童の権限（受信・確認のみ）しか持ちません。

### 管理体制の選択肢

| 案 | 内容 | 長所 | 短所 |
|---|---|---|---|
| **A（推奨）** | 5市町村の教育委員会で連絡協議会をつくり、幹事市町村が事務局 | 地域共通で使える。費用・責任を分担できる | 協議会の設置に合意が必要 |
| B | 1つの市町村（例：沼田市）が単独で導入し、他の町村は後から参加 | 早く始められる | 他の町村が参加するときに取り決めが必要 |
| C | 既存の広域の枠組み（例：利根沼田広域市町村圏振興整備組合）で運営 | 広域の組織が既にある | 所管業務の範囲に入るか確認が必要 |

## 3. 導入の判断に必要な事項のチェックリスト

凡例：✅ システムで対応済み　📄 資料・規程で対応　🤝 協議して決めること　⚠️ 今後の対応が必要

### (1) 個人情報の保護
| 確認事項 | 状況 | 対応 |
|---|---|---|
| 児童の個人情報を扱うか | ✅ | 扱わない（学年ごとの時刻と備考のみ）。備考欄に個人名を書かないよう運用規程で定める |
| 扱う個人情報の範囲 | ✅📄 | 教職員・学童職員の氏名とログインID、学童の電話番号のみ。プライバシーポリシー（案）あり |
| 保護者の情報 | ✅ | 取得しない。通知の登録も匿名（端末の通知先のみ） |
| 個人情報保護法への対応 | 🤝 | 各市町村の個人情報保護の担当部署に、保有個人情報の該当性と必要な手続きを確認 |
| 保存期間と削除 | ✅📄 | 保存期間を過ぎたデータを協議会が削除できる機能あり。期間は運用規程で定める |

### (2) 情報セキュリティ（文部科学省「教育情報セキュリティポリシーに関するガイドライン」・各市町村のポリシー）
| 確認事項 | 状況 | 対応 |
|---|---|---|
| なりすまし・不正ログイン対策 | ✅ | パスワードの暗号化保存、連続失敗時のロック、**2段階認証**（協議会・市町村は必須。学校・学童も必須化できる） |
| 権限の分離 | ✅ | 協議会・市町村・管理職・職員で操作できる範囲を分けている。市町村は他の市町村のデータを管理できない |
| 操作の記録 | ✅ | ログイン・公開・承認・アカウント操作などをすべて記録。改ざんできない |
| 退職・異動者の管理 | ✅ | アカウントを停止でき、停止するとすぐにログアウトされる。最終ログイン日時も確認できる |
| 放置された画面の対策 | ✅ | 管理者は30分操作がないと自動でログアウト |
| 通信の暗号化 | ⚠️ | 本番環境で https を必須にする（設定は用意済み） |
| クラウドの安全性 | 🤝⚠️ | 置き場所の基準を協議。ISMAP 登録済みクラウドや国内のデータセンターが求められる場合は、それに合わせて設置する |
| 第三者による脆弱性診断 | ⚠️ | 本番運用前に実施（費用が発生） |
| 障害・事故時の対応 | 📄 | 運用規程（案）に連絡体制と代替手段（電話連絡）を定めている |
| バックアップ | ✅📄 | 協議会がいつでも取得できる。取得の記録も残る。定期取得の手順は運用規程で定める |
| 学校のパソコンから使えるか | 🤝 | 校務用パソコンがインターネットにつながらない環境（ネットワーク分離）の場合、どの端末から入力するかを各市町村の情報担当と確認。必要ならサイトの接続許可を設定 |

### (3) 教職員の負担（働き方改革）
| 確認事項 | 状況 | 対応 |
|---|---|---|
| 入力の手間 | ✅ | 曜日ごとの一括入力、Excel からの貼り付け、数字だけの時刻入力 |
| 誤った公開の防止 | ✅ | 下書き→変更点の確認→公開の流れ。入力ミスの疑いを警告 |
| 既存業務との二重作業 | 🤝 | 紙の下校時刻表は印刷機能で同じデータから作れる。既存の保護者連絡システム（メール配信等）との使い分けを学校ごとに決める |
| 操作の研修 | 📄 | 1枚ものの操作説明と、15分程度の説明会で足りる見込み（実証で確認） |

### (4) 導入・契約・費用
| 確認事項 | 状況 | 対応 |
|---|---|---|
| 契約の形 | 🤝 | 実証期間は無償提供の協定（協定書案あり）。本格導入時は委託契約や調達手続きを検討 |
| 費用 | 🤝 | サーバー費は小規模なら月数千円程度の見込み。脆弱性診断・保守の費用は別途見積もり |
| 予算のスケジュール | 🤝 | 実証は予算なしで開始可能。本格導入は翌年度予算での対応を想定 |
| 特定事業者への依存 | 🤝 | プログラムの一式を協議会に提供し、別の事業者でも保守できるようにする（著作権の扱いは開発者と協議） |
| 利益相反 | ✅📄 | 開発者は管理権を持たない。開発者が運営する学童も、他の学童と同じ権限・同じ手続き（学校の承認）で利用する |
| 撤退時の扱い | 📄 | 利用終了時のデータの返却・消去の方法を協定書で定める |

### (5) 児童の安全・防犯
| 確認事項 | 状況 | 対応 |
|---|---|---|
| 下校時刻が不特定多数に知られないか | ✅ | 保護者向けページは推測できないリンクでのみ閲覧可能。検索エンジンに載らない。リンクの作り直し・停止が可能 |
| 知らない団体に情報が渡らないか | ✅ | 学童は市町村が登録し、さらに学校が承認した場合だけ情報が届く。学校はいつでも配信を止められる |
| システムが止まったとき | 📄 | 従来どおり電話・紙で連絡する。システムは従来の連絡手段を補うものと位置づける |
| 急な変更の伝達 | ✅ | 当日・翌日の修正は強調して通知。未確認の学童は学校の画面に電話番号付きで表示 |

### (6) だれでも使えること
| 確認事項 | 状況 | 対応 |
|---|---|---|
| スマホ・パソコン・タブレットで使えるか | ✅ | ブラウザだけで利用可能 |
| 見やすさ・使いやすさ（アクセシビリティ） | ⚠️ | 文字の大きさ・色の見分けやすさなどを本番前に点検 |
| 外国籍の保護者への対応 | 🤝 | 必要性を協議（多言語化は今後の検討事項） |

## 4. 進め方（案）

| 時期 | 内容 |
|---|---|
| 第1段階 | 教育委員会へ説明。試作品を実際に操作していただく |
| 第2段階 | 実証実験（1〜2校と、その学校の児童が通う学童で1〜3か月）。協定を結び、無償で実施 |
| 第3段階 | 実証の結果（学校の作業時間、問い合わせ件数、学童・保護者の声）を報告 |
| 第4段階 | 本格導入の判断。協議会の設置、予算、契約、脆弱性診断、本番環境の準備 |
| 第5段階 | 対象を広げる（他の学校・他の町村） |

## 5. よくある質問（想定）

**Q. すでに使っている保護者連絡のシステムと何が違うのか**
A. 一般的な保護者連絡システムは「学校→保護者」の連絡です。このシステムは、学校の外にある**学童への連絡と、その確認状況の把握**が中心で、学年ごとの下校時刻の一覧に特化しています。

**Q. 民間の学習塾が作ったものを使ってよいのか**
A. 管理権は協議会と各市町村が持ち、開発者は管理権を持ちません。プログラム一式は協議会に提供し、特定の事業者に依存しない形にします。

**Q. 先生の仕事が増えないか**
A. 下校時刻表はすでに毎月作られています。同じ内容を入力（Excel から貼り付けも可能）して公開すれば、学童と保護者への個別の連絡が不要になります。実証で作業時間を測定して確認します。
