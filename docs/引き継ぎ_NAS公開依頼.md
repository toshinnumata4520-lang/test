# 引き継ぎメモ：利根沼田 下校時刻共有システム（NAS への公開依頼）

## 1. これまでの経緯（要約）

- 依頼者は学習塾（グリフ。学童も運営）。学校が出す下校時刻を、学童と保護者に共有する仕組みを、利根沼田地域（沼田市・みなかみ町・川場村・片品村・昭和村）の共通システムとして作りたい。
- 試作品を作成済み。リポジトリ `toshinnumata4520-lang/test` のブランチ `claude/school-dismissal-time-sharing-c8cvre`。
- 依頼者は**まだ試作品を実際に見ていない**。スマホや教育委員会への説明で見られるよう、**自社の NAS に公開したい**（「時間割作成」システムを NAS で公開している方法を参考にする）。

### 作ったもの
| 利用者 | できること |
|---|---|
| 学校 | 下校時刻の入力（曜日ごとの一括入力・Excel 貼り付け・`1445` と打つと 14:45）、下書き→変更点の確認→公開、修正公開、学童の確認状況の確認、学童の受信申請の承認、保護者向けリンク、**紙・FAX 用の印刷**（下校時刻のお知らせ／変更のお知らせ。学童が参加していなくても従来どおり FAX できる） |
| 学童 | **お迎え順の一覧**（全校まとめて時刻順）、今日・今週・月の一覧、印刷、お知らせと「確認しました」ボタン、画面を閉じていても届く通知 |
| 保護者 | ログイン不要の閲覧ページ（推測できないリンク）、最近の変更、スマホへの通知（匿名登録） |
| 管理 | 連絡協議会 → 市町村（教育委員会・学童担当課）→ 各校/学童の管理職 の階層。**塾は管理権を持たない**。2段階認証（協議会・市町村は必須）、操作履歴、アカウント停止、自動ログアウト、バックアップ、保存期間を過ぎたデータの削除 |

- 児童の個人情報は扱わない。外部ライブラリなし（Node.js 18 以上のみ）。自動テスト 42 件合格。
- 教育委員会向け資料：`docs/01_教育委員会向け_導入検討資料.md`、`docs/02_運用規程（案）.md`、`docs/03_実証実験に関する協定書（案）.md`
- 作業ルール：`CLAUDE.md`（**ユーザーへの文章はすべて日本語・出力は短く**）

## 2. 依頼したい作業：NAS への公開（デモ用）

「時間割作成」システムを NAS で公開しているのと同じ方法で、この試作品を公開してください。

### 動かし方
- 起動：`node server.js`（または同梱の `Dockerfile` でコンテナ化）
- 初回起動時にデモデータ（架空の学校・学童）を自動作成。パスワードはすべて `demo1234`
- データはファイル 1 つ（既定 `data/db.json`）。コンテナならこの場所をボリュームにして残す

| 環境変数 | 設定 |
|---|---|
| `PORT` | 待ち受けポート（既定 3000）。時間割システムと重ならないポートにする |
| `DATA_FILE` | データの保存先 |
| `SECURE_COOKIE=1` | https で公開するので必ず設定 |
| `TRUST_PROXY=1` | リバースプロキシの後ろに置く場合に設定 |
| `PUSH_SUBJECT` | `mailto:（連絡先メール）` |

### 必須条件
- **https で公開すること**（スマホへの通知は https でないと動かない）
- 公開後、ログイン画面が開き、デモ用ボタン（例：「学校・管理職（沼田第一小 教頭）」）でログインできることを確認
- **サンプルデータのみ。実際の学校・児童のデータは入れない**（本番は教育委員会側のサーバーに移す方針のため）
- 時間割システムの動作に影響を与えないこと
