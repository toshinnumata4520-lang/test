# 利根沼田 下校時刻共有システム 運用規程（案）

> たたき台です。連絡協議会・各市町村の規程や専門家の確認を経て確定してください。

## 第1条（目的）
この規程は、利根沼田 下校時刻共有システム（以下「本システム」）を安全かつ適正に運用するために必要な事項を定める。

## 第2条（定義）
1. 「協議会」とは、本システムを共同で運用する市町村の教育委員会等で構成する連絡協議会をいう。
2. 「市町村管理者」とは、各市町村の教育委員会または放課後児童クラブ担当課で、本システムの管理を担う部署をいう。
3. 「学校」とは、本システムに登録された小学校をいう。
4. 「学童」とは、本システムに登録された放課後児童クラブその他の児童の放課後の居場所を提供する施設をいう。
5. 「管理職」とは、学校の校長・教頭その他の学校長が指定する者、および学童の施設長をいう。

## 第3条（管理体制）
1. 協議会は、本システム全体の運用に責任を持ち、事務局を幹事市町村の教育委員会に置く。
2. 市町村管理者は、所管する市町村の学校または学童の登録と、そのアカウントの発行・停止を行う。
3. 管理職は、自校・自施設の職員アカウントの発行・停止を行う。
4. 本システムの開発者・保守の受託者は、協議会との契約または協定に定める範囲でのみ作業を行い、本システムの管理権を持たない。

## 第4条（アカウント）
1. アカウントは1人に1つ発行し、複数人で共有してはならない。
2. 初期パスワードは本人に直接伝え、本人は最初のログイン後に変更する。
3. 管理職は、職員の異動・退職があったときは、速やかにアカウントを停止する。
4. 市町村管理者は、毎年度4月末までに、所管する学校・学童のアカウントの利用状況（最終ログイン日時）を確認し、不要なアカウントを停止する。
5. 協議会は、2段階認証を必須とする範囲を定める。協議会および市町村管理者のアカウントは、2段階認証を必須とする。
6. 2段階認証に使うスマホを紛失した場合、利用者は速やかに所属先の管理者に届け出る。管理者は本人確認のうえ、2段階認証を解除する。

## 第5条（学童の登録と承認）
1. 学童の登録は、その学童の所在する市町村の市町村管理者が行う。
2. 学童が学校の下校時刻を受け取るには、学校に受信を申請し、学校の承認を受けなければならない。
3. 学校は、自校の児童が利用していることを確認できない学童の申請を承認しない。
4. 学校は、児童の利用がなくなった学童への配信を停止する。

## 第6条（入力・公開）
1. 学校は、原則として前月の＿＿日までに翌月の下校時刻を公開する。
2. 下校時刻に変更が生じた場合、学校は速やかに修正を公開する。
3. 当日または翌日の変更を公開した場合、学校は公開履歴で学童の確認状況を確かめ、未確認の学童には電話等で連絡する。
4. 備考欄その他の入力欄に、児童の氏名など個人を特定できる情報を記載してはならない。

## 第7条（保護者向けページ）
1. 学校は、保護者向けページのリンクを、学校から保護者への連絡手段（学校だより・メール配信等）で配布する。
2. リンクが関係者以外に広まったおそれがある場合、学校は速やかにリンクを作り直し、保護者に再配布する。

## 第8条（障害・事故時の対応）
1. 本システムが利用できない場合、学校は従来の方法（電話・文書等）で下校時刻を連絡する。
2. 不正ログインの疑い、情報の漏えいのおそれ、その他の事故を発見した者は、直ちに所属先の管理者に報告する。管理者は市町村管理者を通じて協議会事務局に報告する。
3. 協議会事務局は、必要に応じてアカウントの停止、リンクの作り直し、関係者への連絡等の措置をとり、各市町村の情報セキュリティポリシーに従って対応する。

## 第9条（データの保存と削除）
1. 下校時刻および公開履歴は、当該年度の終了後＿年間保存し、その後協議会が削除する。
2. 操作履歴は＿年間保存する。
3. 協議会事務局は、毎月＿回以上バックアップを取得し、各市町村の規程に従って保管する。

## 第10条（点検）
協議会は、年1回以上、本システムの運用状況（アカウント、操作履歴、障害の有無等）を点検し、必要に応じてこの規程を見直す。

## 附則
この規程は、令和＿年＿月＿日から施行する。
